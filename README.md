# Brand New World (BNW) - Nation Role Play Website & Wiki

Official presentation website and lore archive for the Nation Role Play (NRP) Discord server **Brand New World (BNW)**.

---

## 🌟 Overview & Features

1. **Direct Discord Integration**
   - Direct link to the server: [**https://discord.gg/xnJqUjF77C**](https://discord.gg/xnJqUjF77C)
   - Large hero button and top navbar button linking directly to the Discord.
   - Built-in one-click button to copy the invite link to clipboard.

3. **Clean Presentation Layout**
   - **2 Category Tabs Per Season:** ⚔️ Major Wars & 🌐 Major Events.
   - **Clean Event Cards:** Titles and narrative previews only — dates and location tags have been removed.
   - **Interactive Dispatch Reader:** Click *"Read Full Dispatch"* on any event to view the full multi-paragraph text.
   - **Live Filter:** Search wars, belligerents, and event titles in real time.
   - **Tactical Radar Canvas & UI Sound:** Ambient scifi/tactical atmosphere (sound toggleable).
